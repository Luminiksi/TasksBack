# TaskFlow Backend

Backend часть TaskFlow — веб-приложения для управления проектами и задачами, вдохновлённого Jira.

## О проекте

Task(в дальнейшем имя определиться, пока это рабочее название) позволяет организовывать работу над проектами, создавать задачи, отслеживать их статусы и управлять процессом выполнения с помощью Kanban-досок.

Этот проект разрабатывается в учебных целях и как портфолио.

## Основные возможности

Планируемые возможности MVP:

- Создание и управление проектами.
- Создание, редактирование и удаление задач.
- Управление статусами и приоритетами задач.
- Работа с Kanban-досками.
- Поиск и фильтрация задач.
- Хранение данных в PostgreSQL.
- REST API для взаимодействия с frontend.

Точный состав зависимостей будет определён при создании приложения(Данный стек пока примерный).

## Архитектура

Backend будет реализован как модульный монолит с REST API.

Основные уровни приложения:

- Controller — обработка HTTP-запросов.
- Service — бизнес-логика.
- Repository — доступ к данным.
- Entity — сущности базы данных.
- DTO — объекты запросов и ответов API.
